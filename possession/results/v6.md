## E2
Config cB (IDSSE + DR, boundary head), fresh seeds 20-24, loss (CE and boundary BCE) x3 on frames within +-5 steps (1 s) of a true H<->A
change where either adjacent run is < 15 steps (3 s). Factor 3 fixed, not tuned. v4 decoder (E1 failed, so not used).
Predicted spells: 381/511, 399/500, 335/402, 364/456, 334/421 (v4: 343, 361, 312, 330, 305).

Caveats (unverified): the margin over the gate is thin (0.6860 vs 0.6839). E2 uses seeds 20-24 while v4 uses 10-14, so seed-ensemble
variation is not separated from the effect (the v4 recipe was not run on seeds 20-24). 5/5 wins and the consistent rise in predicted
spell counts point to a real effect, but its size is uncertain. On one match, differences below ~0.04 are noise.
